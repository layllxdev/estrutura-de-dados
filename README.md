# 📚 Estrutura de Dados

Repositório dedicado às atividades práticas desenvolvidas durante meus estudos de Estrutura de Dados e Algoritmos no curso de Análise e Desenvolvimento de Sistemas do IFPB.

## 💻 Sobre o projeto

O objetivo deste repositório é reunir implementações em Java para praticar lógica de programação, manipulação de dados e compreender o funcionamento de diferentes estruturas de dados e algoritmos.

## 🧩 Conteúdos desenvolvidos

### Estruturas de dados
- Listas encadeadas: lista simplesmente encadeada, duplamente encadeada e duplamente encadeada circular.
- Árvores binárias de busca: inserção, busca e remoção de elementos.
- Árvores AVL: inserção com balanceamento automático e rotações.
- Percursos em árvores binárias: pré-ordem, em-ordem e pós-ordem.
- Tabelas hash: implementações para armazenamento e organização de dados.

### Algoritmos
- QuickSort.
- SelectionSort.
- Percursos recursivos em árvores.

### Exercícios de lógica
- Fatorial.
- Identificação de números pares.
- Cálculo do menor valor.
- Soma de vetores.

## 🛠️ Tecnologias
