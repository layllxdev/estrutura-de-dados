# 📚 Estrutura de Dados

Repositório dedicado às atividades práticas desenvolvidas durante meus estudos de **Estrutura de Dados e Algoritmos** no curso de Análise e Desenvolvimento de Sistemas do IFPB.

## 💻 Sobre o projeto

O objetivo deste repositório é reunir implementações em Java para praticar lógica de programação, manipulação de dados e o funcionamento de diferentes estruturas e algoritmos.

## 🧩 Conteúdos desenvolvidos

- **Listas encadeadas:** lista simplesmente encadeada, duplamente encadeada e duplamente encadeada circular.
- **Tabelas hash:** implementações para explorar o armazenamento e a organização de dados.
- **Algoritmos de ordenação:** QuickSort e SelectionSort.
- **Manipulação de vetores:** soma de vetores.
- **Exercícios de lógica:** fatorial, identificação de números pares e cálculo do menor valor.
